# Crosswalk downloads

Crosswalk draws every Claude Code session on your computer as an isometric city. This repository holds its downloads and nothing else: the code lives in a private repository, and installed copies check here for updates.

**Download the latest version** from [Releases](https://github.com/maxhulker/crosswalk-releases/releases/latest):

- Windows: `Crosswalk-Setup-<version>.exe`. Windows SmartScreen will say it doesn't recognise it: More info, then Run anyway.
- Mac: `Crosswalk-<version>-mac.zip`. Unzip, drag Crosswalk into Applications, open it. macOS may ask you to allow it under Privacy & Security.

Once installed, Crosswalk updates itself from here: it checks at start and every few hours, downloads the new version, and the Crown Tower lights up when it is ready.
